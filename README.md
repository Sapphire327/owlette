# Owlette — The Night Owl

**Мод для игры [Don't Starve Together](https://store.steampowered.com/app/322330/Don_t_Starve_Together/)**

[Steam Workshop](https://steamcommunity.com/sharedfiles/filedetails/?id=3775257196)

---

Owlette — новый персонаж, охотник ночи. Сильна в темноте, слаба на свету. Уникальная фазовая система, дерево навыков из 24 узлов и собственные предметы.

## Базовая статистика

| Параметр | Значение |
|----------|----------|
| Здоровье | 150 |
| Сытость | 150 |
| Рассудок | 175 |

- **Диета:** всеядная, но получает вдвое меньше сытости от немясных блюд.

### Фазовая система

| Фаза | Урон | Скорость |
|------|------|----------|
| День | 0.85x | 0.85x |
| Сумерки | 1.0x | 1.0x |
| Ночь | 1.0x | 1.0x |

### Ночное зрение
- Видит в полной темноте без штрафа к рассудку.

### Светобоязнь
- −2 рассудка/мин на открытом солнце днём.
- В сумерках, ночью и пещерах штрафа нет.

### Линька
- Каждые ~3 утра рядом с Owlette на землю падает Совиное перо (Owl Feather).

### Ограничение сна
- Может спать **только днём**. Ночь — для охоты.

## Предметы

### Claws (Когти)
| Параметр | Значение |
|----------|----------|
| Тип | Оружие (слот рук) |
| Урон | 34 |
| Скорость атаки | 0.4 |
| Прочность | 125 атак |

**Крафт:** 2 Houndstooth + 1 Rope + 2 Owl Feather (наука 1)

### Owl Feather (Совиное перо)
- Материал для крафта. Стак: 20.

### Sharp Dart (Острый дротик)
- Дротик, вызывающий повышенное кровотечение у врагов.

**Крафт:** 1 Owl Feather + 2 Cut Reeds + 1 Houndstooth (наука 2)

## Дерево навыков (24 узла, 15 очков Insight)

| 5 | Двойная добыча | 50% шанс удвоить лут с мелких существ. |
